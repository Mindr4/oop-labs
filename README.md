# OOP Labs

C# object-oriented programming labs, KTU.

## Lab 1: Dog register
A console application that reads/prints a list of dogs from text files and
processes it (filtering, counting, sorting).

**Concepts used:** classes, enums (Gender), file input/output,
separation of logic into utility classes (InOutUtils, TaskUtils).

**Run:** open `Lab1.Exercises.Register.sln` in Visual Studio and press F5.
